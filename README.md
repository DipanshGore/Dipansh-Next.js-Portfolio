# ✦ Dipansh Gore | Full-Stack Engineering Portfolio

> A performance-driven, meticulously crafted developer portfolio built with Next.js and Tailwind CSS. Features a bespoke Emerald/Zinc dark mode aesthetic and advanced interactive physics.

[![Live Deployment](https://img.shields.io/badge/Live_Site-Vercel-10b981?style=for-the-badge&logo=vercel)](https://dipansh-next-js-portfolio.vercel.app)

**🌐 Live URL:** [https://dipansh-next-js-portfolio.vercel.app](https://dipansh-next-js-portfolio.vercel.app)

## 🚀 Architecture & Features

*   **The Matrix UI:** Custom-built SVG circuit board background with asynchronous neon-pulse animations and `mix-blend-screen` integration for authentic ambient lighting.
*   **Bento Grid Layout:** Fully responsive, staggered grid architecture showcasing projects, skills, and enterprise metrics.
*   **Interactive Physics:** Hover states that trigger nested group transformations, dynamic border gradients, and micro-interactions.
*   **Cross-Platform Assets:** Native inline SVGs bypass OS-level emoji rendering limitations (ensuring 100% accurate visual delivery across Windows, macOS, iOS, and Android).
*   **Type-Safe & Server-Rendered:** Built on the Next.js App Router for optimal SEO, zero hydration mismatches, and instant LCP (Largest Contentful Paint).

## 💻 Tech Stack

*   **Framework:** Next.js 15 (App Router)
*   **Library:** React 19
*   **Styling:** Tailwind CSS + custom dynamic utilities
*   **Icons:** Lucide React
*   **Deployment:** Vercel (Edge Network + CI/CD)

## 🛠️ Local Development

To run this project locally, ensure you have Node.js installed and follow these steps:

```bash
# 1. Clone the repository
git clone [https://github.com/dipanshgore/dipansh-portfolio.git](https://github.com/dipanshgore/dipansh-portfolio.git)

# 2. Navigate into the directory
cd dipansh-portfolio

# 3. Install dependencies
npm install

# 4. Set up environment variables
# Create a .env.local file in the root directory and add your required keys:
# RESEND_API_KEY=your_resend_api_key_here

# 5. Start the development server
npm run dev
